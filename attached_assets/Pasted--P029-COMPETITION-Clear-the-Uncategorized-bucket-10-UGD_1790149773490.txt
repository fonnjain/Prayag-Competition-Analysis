# PART 1 — The 10 UGD products

## 1.1 What they are

The UGD range has four families. The competitor master lays them out plainly:

```
RING FIT (SN-8)     U-11C  U-12C  U-13C  U-14C  U-15C  U-16C
RING FIT (SN-4)     U-11B  U-12B  U-13B  U-14B
SELF FIT (SN-8)     U-11CS U-12CS U-13CS U-14CS U-15CS U-16CS     <- created by P019r2
SELF FIT (SN-4)     U-11BS U-12BS U-13BS U-14BS                   <- created by P019r2
```

The `S` suffix means **Self Fit**. Each Self Fit product is the same size and the same SN rating as a Ring Fit sibling, **at an identical price**. The two ranges differ only in joint type.

## 1.3 The size field

The siblings carry `size = NULL`, so copying the sibling leaves size empty. The sizes are known and are listed above — set them **only if the schema has a size field that is currently empty on both the Self Fit product and its sibling**, and set them on both. Report what you did.

If setting size on the Ring Fit siblings is outside what you are comfortable doing in this prompt, leave all sizes alone and say so. That is a fine answer.

## 1.4 Naming — report, do not change

The Ring Fit products are named `UGD PIPE (6 MTR) SN-8` and `UGD PIPE (6 MTR) SN-4`. The names say nothing about Ring Fit.

So once the Self Fit products are classified, the catalogue will hold **two products with the same name, same series, same size and same price**, distinguishable only by code. `U-11C` and `U-11CS` will both read `UGD PIPE (6 MTR) SN-8`.

**Do not fix this here.** Report the current name of all 20 UGD products so it can go to Prayag as a naming decision. The likely answer is `RING FIT` and `SELF FIT` in the names, but that is Prayag's call and it belongs in the name-change path, not in a classification fix.

## 1.5 Why they landed in Uncategorized

Report it. These products were created under P019r2, so either the creation path does not require a classification, or it accepted one and dropped it.

**If a product can be created without a classification, that is the real defect** — these ten are the symptom. Say which it is and what it would take to require classification at creation. Do not implement that change in this prompt.
