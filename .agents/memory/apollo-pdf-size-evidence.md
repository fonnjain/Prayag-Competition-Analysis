---
name: Apollo PDF size evidence
description: Caution about manually transcribed size samples and the limit of positional extraction.
---

When a PDF size check contradicts a previous audit, use the size printed beside the exact supplier code on the actual PDF page, and explicitly report the corrected observation. Never tune extraction to force agreement with a human-transcribed sample.

**Why:** Two sizes previously recorded as visually confirmed were different from the sizes actually printed beside those codes. Correctly filling the PDF size column also revealed dimension-order and incomplete-workbook differences, which are not automatically evidence of a different product.

**How to apply:** For Apollo PDF rechecks, pair the code and its size from the same page and table row, visually inspect disagreements, and separate field agreement from product-identity adjudication. Preserve populated historical extraction evidence rather than silently rewriting it.
