Use **TRIANGULAR**, not the source workbook misspelling “TRIANGULER,” for CH concealed-valve product names.

The confirmed range order is:

- 72 / 82 — TRIANGULAR
- 74 / 84 — GRACIA
- 76 / 86 — MACASA
- 78 / 88 — URBONA
- 79 / 89 — SAGA
- 80 / 90 — VIVA

The numeric part identifies the range across all three valve types: no suffix is long quarter-turn, `F` is full turn, and `QS` is short quarter-turn.

**Why:** The user confirmed this from two independent signals: each numeric code keeps the same range across valve-type suffixes, and the ¾-inch and 1-inch price tiers occupy matching positions. The earlier supplied list was reversed and duplicated SAGA where VIVA belongs.

The same confirmed spelling applies to the related `UH-72`, `UH72-S`, `UH82`, and `UH82-S` products: “TRIANGULER” is a source spelling error, not a distinct range.

**How to apply:** Keep this order and spelling when correcting, importing, or reviewing CH concealed-valve names, and preserve TRIANGULAR for the confirmed UH codes as well. Other product families still require their own evidence.
